Mustafa Ghauri's Instagram + LinkedIn System
⚠️ RESTRICTED USE
This system is ONLY for Mustafa's own personal brand content (Instagram + LinkedIn). Not for client work. Not for any other person's personal brand. If you're a teammate using this doc, it applies only to Mustafa/FASTECH's own content — nothing else.
1. What This System Does
One sentence: turns a weekly topic list into ready-to-post Instagram and LinkedIn content, using fixed templates and proven caption formats.
2. The Weekly Workflow
Step 1: Topics get proposed for the week.
Step 2: Mustafa approves or changes topics. Nothing gets written before this.
Step 3: Once approved, full content gets scripted — slide text, captions, hashtags.
Step 4: Content goes to the GPT bot (template execution) to generate the actual image/carousel.
Step 5: Finished post goes into Buffer for scheduling.
3. The 4 Content Pillars
1. AI/editing tactics — tools, workflows, automation
2. Agency/systems — how FASTECH runs, scales, hires
3. Brand strategy — frameworks applied to real examples
4. Build-in-public — real wins, losses, honest lessons
4. Template Library
Each template number matches a fixed design layout. Never redesign — only swap text content.

5. Face Placement Rule
Face on slide 1 is NOT mandatory. It's a choice per template. Some templates (like Template 2) put the face near the end, at the emotional payoff moment. Always follow what's specified — don't default to slide 1.

7. Instagram Caption Format
SHORT. Punchy. Line breaks. Never long paragraphs.
1. Hook line
2. 2-4 short expanding lines
3. Soft CTA (save/comment/follow) 📌
4. Hashtags (8-16, niche + reach mix)
5. Keyword bracket list — plain search phrases, e.g. [video editing agency, client management tips]
8. LinkedIn Caption Format (Different from IG!)
LONG-FORM. Personal story. This is Mustafa's best-performing format.
1. Hook line — write fresh, never reuse the IG slide text word-for-word
2. Real scene/moment — specific detail, not generic
3. Realization/turn
4. Reframe line — the quotable, sharp line
5. Specific engagement question (not generic)
NO hashtags. NO caption-cue trick. These are IG-only.
9. Photo Generation Notes
• Background/outfit/scenario swaps: reliable, easy
• Full pose/angle changes: harder, expect a few tries
• Match photo mood to caption tone (calm caption = calm photo, not high energy)
10. Quick Reference Checklist
☐ Topics approved before scripting
☐ Correct template number assigned
☐ Face placement specified (not assumed)
☐ IG caption ≠ LinkedIn caption (different formats used)
☐ Hook lines not copy-pasted across platforms
☐ Single posts have caption-cue text if needed
