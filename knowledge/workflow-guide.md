Social Media Manager SOP
Content-to-Design Workflow — for the SMM and any team members she brings on
Every post starts one of two ways. Find your path below.
PATH A — Content Written First
Use this when the content manager already wrote the post copy.
 1
Content is written. That's your starting point.
 2
Go to Pinterest. Find 2-3 references that match the vibe/idea of the content.
 3
Go to Claude. Open the Design Brief skill.
 4
Fill in the brief. Include the Pinterest reference link in the "Reference / Inspiration" field.
 5
Save everything in the post's folder (see Folder System below).
PATH B — Reference Found First
Use this when you spot a great design on Pinterest before content exists.
 1
Scrolling Pinterest. Spot a design with real potential for our page.
 2
Save the reference image or link.
 3
Go to Claude. Use the content-writing skill.
 4
Ask Claude to write content in the same format/text ratio as the reference — tailored to our
audience. Claude knows our ICP.
 5
Content is ready. Now follow PATH A starting at Step 3 (Design Brief).
The Post Folder System
Every post gets its own folder inside the FASTECH.PAK Drive folder.
 Name each folder by number: Post 1, Post 2, Post 3...
 Each folder holds: the Pinterest reference image(s), AND the final Design Brief (from Claude).
 The designer opens the folder and has everything needed. No extra messages, no hunting for
context.
Rules to Remember
 Never skip the Design Brief step. The designer should never have to guess.
 Always include the Pinterest reference link in the brief — even a rough match helps.
 Folder name = post number, every single time. Consistency is the whole point.
 Unsure about brand voice or visuals? Ask. Don't guess.
This SOP covers the content → design handoff only. Posting, scheduling, and reporting are separate steps — ask your
manager if those aren't covered yet.
