# Design Brief — Post 01 Instagram (Personal Story)
Date: 2026-08-28
Platform: Instagram (@mustafaghauri._)
Type: Single image
Post: "My first client paid me $50. I spent it on software, not food."

---

VISUAL CONCEPT:
A near-black card with a single stark white number "$50" dominating the frame — small subtext below anchors the emotional weight. Feels like a confession, not a flex.

COVER TEXT:
"My first client paid me $50."

SUBTEXT:
"I spent it on software, not food."

COLOR MOOD:
Very dark navy (#020810) background · White text (#ffffff) dominant · Single cyan accent (#00e5ff) as a thin underline or glow on "$50"

VIBE:
"Build-in-public raw" — real, not polished. Not a motivational poster. More like a screenshot of a feeling.

---

BACKGROUND:
Very dark navy (#020810). No gradients, no patterns. Pure darkness — the text does the work. Optional: extremely subtle grain texture at 3% opacity to keep it from feeling flat.

FOREGROUND ELEMENTS:
- "$50" in massive weight — 80–100px bold, white, center-aligned. This is the visual anchor.
- Below it, in 18–20px regular weight, 65% opacity: "My first client paid me $50. I spent it on software, not food."
- Bottom right corner: tiny "@mustafaghauri._" in monospace 10px, 40% opacity

TYPOGRAPHY:
- "$50": Inter/Rajdhani Bold, 90px, white, no letter-spacing
- Subtext: Inter Regular, 18px, rgba(255,255,255,0.65)
- Handle: Space Mono, 10px, rgba(255,255,255,0.4)

PHOTO DIRECTION (no photo needed for this post):
Text-only. The story is the visual. No Mustafa photo required.

---

CANVA EXECUTION NOTE:
1. Open Canva → new Instagram post (1080×1080)
2. Set background: solid fill #020810
3. Add text box center-aligned: type "$50" → font Raleway or Montserrat Black → size 140 → color #ffffff
4. Add cyan glow: duplicate "$50" layer → blur 20px → tint #00e5ff → set to 15% opacity behind main text
5. Add second text box below: the two-line subtext → Inter Regular → 22px → color rgba(255,255,255,0.65)
6. Bottom-right corner: @mustafaghauri._ → monospace font → 12px → 40% opacity
7. Optional: add a noise/grain overlay layer at 3% opacity to prevent flat look
8. Export as PNG, 1080×1080
